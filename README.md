## ENGICARE

EngiCare is a centralized, modern web-based platform for Muğla Sıtkı Koçman University students and staff to report and track campus and faculty issues, such as damaged equipment, classroom problems, Wi-Fi drops, lighting failures, and other maintenance needs. Today, these problems are reported informally, which causes delays and leaves no clear record of whether an issue was fixed. EngiCare solves this by letting users submit a report with a description, category, and location, then follow its status until resolution, while administrators review, update, and close reports from one place. The expected value is faster reporting, quicker repair times, better tracking, and more efficient issue resolution for everyone.
The system will be built with React, Java/Spring Boot, and SQL by a four-person team. This M1 milestone formalizes the project: it defines the objectives, scope, constraints, assumptions, stakeholders, team roles, delivery approach, success criteria, and an initial risk register, and it sets the plan for the next milestone. The main outcome is a shared, agreed baseline for what we are building, how we will deliver it, and how we will judge success, establishing a clear project scope, team roles, and an Agile development plan to build a complete and secure system.
